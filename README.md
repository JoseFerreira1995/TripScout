# Travel Price Finder App

A modern, minimalistic travel application for finding the best prices on flights, accommodations, and discovering top attractions for your next destination.

## Overview

This application provides a streamlined experience for travelers to search and compare:

- **Flights**: Browse and compare flight options with detailed pricing and duration information
- **Accommodations**: Discover hotels, apartments, and luxury stays with ratings and reviews
- **Attractions**: Explore must-see landmarks, museums, tours, and experiences

## Features

### Core Functionality

- **Smart Search Bar**: Search by destination, dates, and number of guests
- **Tabbed Navigation**: Easily switch between flights, stays, and attractions
- **Flight Cards**: View departure/arrival times, duration, stops, and competitive pricing
- **Accommodation Cards**: Browse properties with images, ratings, reviews, and nightly rates
- **Attraction Cards**: Discover experiences with descriptions, duration estimates, and entry prices

### Design Philosophy

- **Minimalistic**: Clean, uncluttered interface focused on essential information
- **Modern**: Contemporary UI using Tailwind CSS and Radix UI components
- **Responsive**: Seamless experience across desktop and mobile devices

## Tech Stack

### Frontend Framework

- **Next.Js**: Modern React with hooks and functional components
- **TypeScript**: Type-safe development experience

### UI & Styling

- **Tailwind CSS 4.1**: Utility-first CSS framework
- **Lucide React**: Beautiful icon library
- **Shadcn**: Additional UI components and icons

## Components

### SearchBar

Allows users to input:

- Destination city
- Travel dates
- Number of guests

### FlightCard

Displays:

- Airline name and logo
- Departure/arrival times and airports
- Flight duration
- Number of stops
- Price per person

### AccommodationCard

Shows:

- Property name and image
- Location details
- Star rating and review count
- Nightly price
- Property type (Hotel, Apartment, Luxury)

### AttractionCard

Features:

- Attraction name and image
- Description
- Rating
- Estimated duration
- Entry price
- Category (Landmark, Museum, Tour)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm package manager

### Installation

1. Clone the repository

```bash
git clone https://github.com/<your-username>/TripScout.git

```
```bash
cd my-app
```

2. Install dependencies:

```bash
npm install
# or
pnpm install
```

3. Start the development server:

```bash
npm run dev
# or
pnpm dev
```
